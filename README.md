# The Ash Road

System design and development notes for an original cooperative RPG built with Unreal Engine.

## Project status and scale

![The Ash Road project status](docs/status/project-status.png)

**[306.41 GB and 1,232,117 files](docs/status/README.md)** in the measured main physical workspace. Archives and generated copies are included; this is not the game's download size.

**140,410 code-only lines** across 1,657 active source files. The [source and documentation inventory](docs/status/README.md#source-code-documentation-and-workflows) also records 705 active Markdown documents and distinguishes project workflows from the separate local skill library.

**Journey40 is promoted. Journey41 compiled, but packaging was interrupted.** Four new residents and five bandit profiles have source-world evidence. The [full status report](docs/status/README.md) separates release readiness, source integration, measured storage and key technologies.
